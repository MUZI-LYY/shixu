# 拾序使用说明

拾序 0.2.1 · Mac 本地试用版

打开与升级
打开「拾序.app」，或打开 Shixu-0.2.1-arm64.dmg 后拖入应用程序。
先退出旧「事务工作台」，避免两份应用同时访问同一数据目录。
继续沿用 ~/Library/Application Support/Mac Voice Workspace/，已有待办、笔记、录音和设置保留。App ID 与加密存储沿用旧版；系统可能要求重新授予权限。
应用仍常驻屏幕顶部和菜单栏。点击顶部胶囊展开，或鼠标移到胶囊处按空格。
本版保持原暗色界面，应用图标换为已确认的深色发光叠页 Logo；右上角钥匙图标进入密钥，齿轮进入设置。镜子默认封面已替换为摄像头占位图，点击才开启摄像头。
本地 ad-hoc 签名，未 Apple 公证；系统阻止打开时，请在系统设置 → 隐私与安全性查看「仍要打开」。

语音待办与会议录音快捷键
右上角设置 →「语音与录音快捷键」。两组默认关闭。
点击对应输入框后按下组合键，勾选启用，再点「保存快捷键」。
建议：Control+Option+Space 用于语音待办；Control+Option+R 用于会议录音。可以自行改成 Command/Control/Option/Shift 与字母、数字、空格或 F1–F12 的组合。
语音待办：按住开始说话，松开结束，自动转写并生成操作预览，确认后创建或修改待办。单段上限 2 分钟。
会议录音：按一次开始，再按一次结束并保存。已有录音时不会同时开启另一段。
两组都需要 macOS 输入监控权限；第一次启用按系统提示授权，授权后回到设置重新启用，必要时重启应用。系统列表可能显示拾序或 workspace-native。录音另外需要麦克风权限。
如果组合键已被本应用或系统占用，会显示错误并保留原配置。

API 配置
首页「API 设置」配置阿里云百炼实时转写 Key；地域须与 Key 一致。
语音待办依赖百炼转写。会议录音无 Key 仍可保存音频，但不会保证产生转写。
会议整理、复杂事务理解、翻译使用 OpenAI-compatible 模型：填写自己的 Base URL、模型名和 API Key。
云转写会发送音频到百炼；会议整理会发送转写文本到配置的模型。密钥通过系统安全存储加密。
会议录音记录麦克风输入，当前没有独立系统音频捕获。在线会议若戴耳机，远端声音可能不在录音中。

待整理
在首页输入临时想法或资料文字，点击「存到待整理」。
非语音待办的录音结束后会进入待整理，可打开原录音、发起会议整理。
列表支持提取待办、存为笔记或移出待整理。移出录音条目不删除原始录音。

同一个主助手，两套专业流程
会议整理：首页「会议整理」，或在录制页打开一段录音，点击「会议整理」。可以粘贴或修改转写。
主助手生成摘要、明确决定、待确认问题和行动项，并给行动项保留原文依据。
结果自动存到待整理。检查标题、负责人和截止日期后，逐条点击「确认由我跟进，加入待办」。同名未完成任务会阻止重复创建。
每日安排：首页「每日安排」，选择日期、工作时间、任务，并填写每项预计耗时。
系统读取日历，用可验证的排程规则避开忙碌时段、过去时间和截止约束，提出安排。
每条建议都需要确认，才写入日历。保存前会再次检查冲突；没有足够时间、已逾期或缺少耗时，会显示原因。
这是同一个流程调度入口的两个专业工作流，不是多个独立后台 Agent。

Mac 日历
首页任务右侧「日历」，以及创建待办后的「加入日历 / 改期」，可以指定实际开始和结束时间。
「确认写入日历」后，默认按需在 Mac 自带日历 App 中创建名为「拾序」的日历分类；也可以选择已有可写日历。
没有日历账户时，先在 Mac 日历中启用本地或云端日历。首次使用要授予日历访问权限。
仅有日期的任务不会自动加入全天日历；需要在确认窗口勾选「作为全天事项」。
截止日期与执行时段分开保存。任务周五到期，可以安排周三执行。
同一个任务再次保存会更新已关联事件，避免重复创建。若事件被删或关联标记变化，会明确提示，不擅自覆盖其他日程。
当前为工作台向日历的显式写入/改期，不是双向同步。直接在 Mac 日历改动，不会反向修改本地任务；完成、删除或撤销本地任务也不自动删除日历事件，需要在日历中处理。

保留功能
原有待办、笔记、链接、录音、音乐、番茄钟、镜子、密钥以及截图 OCR/英文翻译继续保留。
图片 OCR 在本机执行；翻译需要模型。具体 OCR 操作见原试用说明的相关部分。

验证范围
Node 单元检查、原有 Electron 回归、新工作流 UI/IPC 和重启保存已检查。
新流程测试对模型、音频设备和日历账户使用模拟；覆盖确认执行、重复防护、改期关联和快捷键启动/释放竞态。
原有本地 OCR、复制和任务操作使用真实桌面环境验证。
真人语音质量、实体快捷键与系统输入监控权限、真实模型服务和真实日历账户读写，需要首次配置授权后实测；没有向个人日历写入测试事件。
