# 拾序 v0.2.1 · Mac 个人试用版

本次发布面向 **macOS 13+、Apple Silicon（arm64）**。下载本 Release 附件 `Shixu-0.2.1-arm64.dmg`，打开后将「拾序」拖入「应用程序」。`.sha256` 为完整性校验文件。

## 本版变化

- 应用图标更新为已确认的深色发光叠页造型：干净银白纸面、青蓝至淡紫轮廓光。
- 延续 0.2.0 的待整理、独立语音/会议快捷键、会议整理与每日安排流程。
- 支持确认后写入 Mac 日历，默认按需创建「拾序」分类；任务截止日期与实际执行时段分开，同一任务关联改期避免重复创建。
- 保留暗色界面、原有个人工具，密钥与设置位于右上角，镜子使用中性占位图。

## 开始使用

首页可以直接试文字待办。语音待办需要百炼实时转写 Key；会议整理、复杂理解与翻译需要 OpenAI-compatible 模型配置。

录音快捷键在右上角设置中分别启用：按住说话、松开转待办；会议录音按一次开始、再按一次结束。需要输入监控与麦克风权限，未配置时不会默认开启录音。

## 升级与已知边界

先退出旧「事务工作台」或「拾序」，再启动新版。继续使用 `~/Library/Application Support/Mac Voice Workspace/`，保持旧数据与 App ID。权限或系统加密 Key 可能需要重新授权/输入。

- 采用本地 ad-hoc 签名，未 Apple 公证；若 macOS 拦截，请在「系统设置 → 隐私与安全性」查看「仍要打开」。
- 会议录音是麦克风输入，尚不包含独立系统音频捕获。
- 日历是显式单向写入/改期，任务完成或删除不自动删除事件，外部日历编辑也不回写待办。
- 新工作流对模型、音频设备与日历账户使用模拟验证；真实语音、实体快捷键及真实账户效果需要配置授权后实测。没有向个人日历写入测试事件。
- 当前不提供拾序的 Windows 或 Intel Mac 安装包。
